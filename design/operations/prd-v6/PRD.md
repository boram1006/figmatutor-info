## 채운 기본값 요약

- 결과 공개 범위 = 결과 + 총점 + 항목별 점수 + AI/휴먼 코멘트.
- 미입상 팀도 결과 화면 노출.
- 순위=배지, 특별상=상 이름 배지.
- 점수 산식·가중치는 화면에 비노출.

## 남은 [미정] 4가지

1. 발표 전 대기 상태(`RESULT_PENDING`) 포함 여부 — 기본은 발표 후에만 진입.
2. AI 소스코드 분석 결과 공개 수준 — 기본은 항목 점수+요약 코멘트.
3. AI↔휴먼 점수 산식/가중치 노출 여부 — 기본은 비노출.
4. AI 항목별 점수 공개 여부 — 기본은 공개(요약 수준).
