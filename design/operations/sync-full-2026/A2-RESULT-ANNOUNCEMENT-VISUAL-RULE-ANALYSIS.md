# A2 Result Announcement Visual Rule Analysis

Source: `snapshot-representative-archetypes-batch.json`
Frame: `H-02_first-round-result_H2`
nodeId: `1:22713`
Archetype: A2 / campaign-announcement

## Composition
- 1440 desktop, 120px side rail
- header ~79px
- large hero area with background image / overlay
- hero content uses 1200px rail
- body section begins after hero and uses dark raised surface
- winner/result cards use 3-column grid, 384px each, 24px gap
- card: white surface, border-default, 24px padding, radius 16
- internal CTA/button radius 12
- status/category chips: 4/8 padding, radius 8
- supporting announcement section uses larger vertical spacing and centered content
- countdown block is a strong standalone module, using pill/rounded treatment

## Typography hierarchy
- hero title: 54/60/600
- supporting large section title: 40/48/600
- card title: 20/28/500
- body: 16/24
- metadata: 14/20
- caption: 12/16

## Common grammar confirmation
- 1200px rail
- 24px card padding
- 16px primary card radius
- 12px CTA/internal radius
- 4/8 chip padding
- clear section hierarchy rather than arbitrary free-floating blocks

## A2-specific
A2 is allowed to be visually expressive:
- large hero imagery
- dark section background
- celebratory/campaign emphasis
- large title scale
- promotional countdown/CTA modules

These should not be generalized to operational screens.
