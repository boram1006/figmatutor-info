## 판정 구분 (공통)

- **Pass**: 기능 이상 없음
- **Fail**: 기능이 누락되거나 불안정한 테스트 케이스로 재확인이 필요한 경우
- **Skip**: 재현이 필요하거나, 발생 빈도가 높지 않다고 판단한 경우

## 표 컬럼

각 QA 목록은 `# / Class / Sub1 / Sub2 / Summary / Priority / Result` 형식이다.
Summary 뒤 괄호 안 내용은 원본의 판정 사유·비고(재현 필요, 기획 변경 등)를 옮긴 것이다.

## 알려진 Fail 항목 (재확인 대상)

- **ver.1 / 1차 심사 #88, #89**: 증감 버튼 최솟값·최댓값 비활성 상태에서 클릭 시, 값 변경이 없어도 저장 버튼이 활성화되는 이슈.
- **ver.1 / 전체점수 현황보기 #16**: 0점 입력/저장이 되고, 0 입력 시 값 수정이 안 되는 부분 수정 필요.
- **ver.1 / 전체점수 현황보기 #63**: 서버 저장은 마지막 저장 기준으로 되나, 개별 심사표 수정사항이 전체 심사표 UI에 반영 안 되는 부분 수정 필요.
