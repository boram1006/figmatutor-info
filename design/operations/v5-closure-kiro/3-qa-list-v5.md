# v5 최종보고서 제출 — QA 리스트 (보완된 PRD 기준)

근거: `design/operations/prd-v5/PRD.md` + 현재 Figma 실제 상태(`design/04-screens/coverage/design-coverage.md`).
형식: 기존 배포 QA 리스트(`design/operations/qa/`)와 동일 — `# / Class / Sub1 / Sub2 / Summary / Priority / Result`.

- Result는 미실행이므로 `-`.
- Summary 뒤 `[Q#]`는 `1-prd-decisions.md`의 해당 항목과 연결된 케이스다.
- **2026-09-25 결정 반영**: Q1~Q7·Q9가 확정되어 대부분 expected 고정 가능. 다만 **서버 처리(UI 미표현)로 확정된 항목**은 UI QA 대상에서 제외/조정한다:
  - **Q3(완료 판정 서버 처리)**: A-31 #9 "완료 판정식" UI 검증 → **UI QA 제외**(서버 값 반영만 확인).
  - **Q2(신규 메뉴 서버 제공)**: A-31 #8 prefill은 "7개 승계 + 5번만 추가" 기준으로 확정. 5번 신규 메뉴 내용은 서버 제공이라 UI 값 검증 제외.
  - **Q7(timestamp UI 미표현)**: 제출일시 절대표기 관련 케이스(A-30 #14)는 기존 공통 시간 표기 규칙을 따르며 신규 timestamp 표기 검증 아님.
  - **Q9(공통 로딩/에러)**: A-30 #16 스켈레톤·#17 에러 재시도는 화면별 정의 대상이 아니라 공통 처리 → 별도 화면 QA에서 제외(공통 QA로 이관).
  - **Q1(재제출=Warning)**: A-30 #7 배지가 Warning 계열인지 검증(확정됨).
  - **empty(Q9)**: A-30 #2는 "필요 판단 시 추가"이므로 디자인 확정 전 BLOCKED 유지.

## 커버리지 note

- A-30 4상태(작성중/제출완료/재제출/미진출)는 현재 디자인에 **존재**(coverage COVERED) → QA 실행 가능.
- A-32 SUBMITTED_LOCKED / CHANGED_AFTER_SUBMIT / DEADLINE_PASSED는 **디자인 미존재**(MISSING_STATE) → 관련 QA(#11,#12,#15)는 `2-missing-designs.md`의 생성 완료 후 실행 가능.
- `[Q#]` 표시 케이스는 `1-prd-decisions.md`의 확인 필요 항목이 확정되기 전까지 expected를 고정하지 않는다.
- SECTION 2~8 내부 필드 QA는 PRD 스코프 밖이므로 이 리스트에서 제외했다.
