# v5 Manual QA Checklist

정본 QA: `qa-cases.yaml`  
정의되지 않은 항목: `qa-gap-audit.md`

총 45개 TC를 매번 개별 실행하기보다 아래 6개 journey로 묶어 실행한다.

## Result
- Pass: expected와 일치
- Fail: expected와 불일치
- Skip: 현재 fixture/환경에서 재현 불가
- Blocked: PRD 또는 backend 상태가 부족해 실행 불가
